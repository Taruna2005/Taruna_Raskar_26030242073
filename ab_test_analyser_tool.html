Open rate = opens ÷ sent. Click rate = clicks ÷ sent. Each test is a two-sided two-proportion z-test with a pooled proportion, comparing A to B. A positive z-score means A has the higher rate. The result is significant when the p-value is below 0.05.

  • Paste from a spreadsheet or CSV. Start with a header row. Two layouts work:
  • One row per variant: test_id (optional), element_tested, variant (A or B), sent, opens, clicks
  • One row per test: test_id (optional), element_tested, sent_a, opens_a, clicks_a, sent_b, opens_b, clicks_b
  • Without test_id, the first A row for an element pairs with the first B row for the same element, and so on.
  • No header? Use 5 columns (element_tested, variant, sent, opens, clicks) or 7 columns (element_tested, then the six one-row-per-test counts).
