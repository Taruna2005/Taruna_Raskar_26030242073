# T53 — Email A/B Test Analyser

AI-powered tool that calculates open/click rates and statistical 
significance for email A/B tests, analyzes 20 existing tests, 
and proposes 5 new test ideas.

## 🔧 How to use the tool
This repo includes a working tool: **ab_test_analyser_tool.html**
GitHub displays it as code, not as a working page, so to actually use it:
1. Click on the file name above (or below in the file list)
2. Click the **download icon** (top right of the file view) 
   or "Download raw file"
3. Open the downloaded file in any web browser (Chrome, Edge, etc.)
4. The tool will open and work normally — paste data, click buttons, etc.
